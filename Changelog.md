# Changelog

### The way that versions are tracked has been changed. Thus the change from "Version 15" down to "Version 2".


## **2.1.0.0**

- #### Vehicle Changes:

	- Mosquito T.R. 33 → Sea Mosquito T.R. 33
	- Corrected formatting of Sea Harrier F.R.S. 1
	- The first hyphen has been removed from Japanese vehicle names (ex. Ki-10-I → Ki 10-I).
	- Restructured a few Japanese stat cards (RCV (No.1), MCV (No.3), TK (No.3) (2006), and TK (No.3) (2009)).
	- Reverted a few Chinese vehicles which got name changes a while back.
	- 76 SPG → 76mm SPG
	- 100 SPG → 100mm SPG
	- 122 SPG → 122mm SPG
	- 152 SPG → 152mm SPG
	- AMX M 4 Mle.49 → AMX M 4
	- Patria AMV (CT-CV) → AMV (CT-CV)
	- AMV (BMP-3) → AMV (2K23)

	- NATO Reporting Name for MiG-21 2000 added as "Fishbed 2000".


- ### Weaponry Changes:

	- Have begun the process of overhauling all of the ground and aircraft weapons in the game. 


- ### Modification Changes:

	- Kh-29 /K-59 → Kh-29 / 59


- ### Other Changes:

	- "?" → "U" (RWR IDs)


- ### Fixes:

	- Fixed an issue where J16s RWR ID was appearing in team list instead of its name.
